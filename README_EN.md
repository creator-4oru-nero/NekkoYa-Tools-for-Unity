## Install with VCC (after publication)

1. In VCC, open **Settings → Packages → Add Repository** and add the URL below.
2. Open **Manage Project** for your project and add **NekkoYa Tools for Unity**.
3. Open Unity 2022.3.22f1 and wait for compilation. Enable VCC's prerelease package visibility if the development candidate is hidden.

```text
https://creator-4oru-nero.github.io/NekkoYa-Tools-VPM/index.json
```

Repository page: https://creator-4oru-nero.github.io/NekkoYa-Tools-VPM/

The URL becomes available only after GitHub Pages and the first package Release are published. Adding workflow files does not publish it. Back up your project and remove duplicate original scripts or a UPM Git installation before migrating. PhysBone Organizer additionally requires VRChat SDK Avatars.
