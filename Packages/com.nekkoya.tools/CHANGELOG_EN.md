- Added PhysBone Organizer as the seventh tool, with three-language guidance, armature detection, settings/reference migration and Undo.

- Bundled six tools for installation with Unity Package Manager.
- Added top-level NekkoYa menus with English tool names and shared Japanese, English and Korean settings.
- Improved preset Undo, read-only preset protection, pre-rename validation and rollback for failed folder creation.
- Protected BOOTH drafts when saving fails and added an unsaved-data prompt.
- Preserved authored descriptions, stored data and presets; added installation guides in three languages.

Final version and publication date require approval. Interactive Unity verification is pending.
