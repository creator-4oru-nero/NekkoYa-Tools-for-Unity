# 업데이트 이력

## 1.0.0-pre.2

- Unity Safe Mode를 유발하는 CS1736 컴파일 오류를 수정했습니다. 기본 권장 문구는 결과 추가 시 번역됩니다.

## Unreleased — 1.0.0 후보

- PhysBone Organizer를 일곱 번째 도구로 추가했습니다. 3개 언어 안내, 아마추어 감지, 설정/참조 이전과 실행 취소를 지원합니다.
- 정리 전에 편집 불가 참조와 대상 변경을 확인합니다. SDK가 없으면 PhysBone 정리 기능만 비활성화합니다.

- 6개 도구를 Unity Package Manager로 설치할 수 있도록 구성했습니다.
- 최상위 NekkoYa 메뉴에 영어 도구 이름을 배치하고 공통 일본어/영어/한국어 설정을 추가했습니다.
- 프리셋 Undo, 읽기 전용 프리셋 보호, 이름 변경 전 재확인 및 폴더 생성 실패 시 되돌리기를 개선했습니다.
- BOOTH 저장 실패 시 초안을 보호하고 미저장 데이터 확인을 추가했습니다.
- 기존 상품 본문, 저장 데이터와 프리셋을 보존하고 3개 언어 설치 가이드를 추가했습니다.

정식 버전과 공개일은 승인 후 확정합니다. Unity 실제 검증은 미실시입니다.

## PhysBone Organizer 0.1.0 — 원본

- 추가 제공된 소스를 변경 없이 보관했습니다. 별도 `physbone-organizer-v0.1.0` 태그로 관리하며 기존 6개 도구의 0.1.0은 변경하지 않습니다.

## 0.1.0 — 원본

- 사용자가 제공한 도구 6개를 변경 없이 보관했습니다. 원본 ZIP과 소스는 `Original/v0.1.0`에 있습니다.
- 원본 기능과 기존 문제를 유지합니다. UPM 지원 등 개선은 1.0.0 후보에 포함됩니다.
