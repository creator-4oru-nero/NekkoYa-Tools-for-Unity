# プレハブ差分反映

Unity 2022.3向けのEditor拡張です。Unityのメニュー `Tools > NekkoYa > プレハブ差分反映` から開きます。

1. **反映元**にHierarchyのGameObjectをドラッグします。
2. **反映先**にProjectの既存 `.prefab` アセットをドラッグします。
3. **差分をプレビュー**で追加・削除・設定変更を確認します。値の左が更新前、右が更新後です。
4. **バックアップを作成して全差分を反映**を押し、確認ダイアログで実行します。

## 反映内容

- 子階層、並び順、コンポーネントとその順序、Unityがシリアライズする設定値。
- ルートも含む名前、ローカル位置・回転・スケール、Active、Tag、Layerなど。
- 内部オブジェクト参照、アセット参照、配列、SerializeReferenceのフィールド。
- 反映先にしか存在しないオブジェクトやコンポーネントの削除。

差分の階層は `Root/Child[0]` のように兄弟インデックスで表示します。名前を変更した要素や同名の要素も区別します。プレビューは保存可能な値の比較です。Prefab接続情報は比較対象外で、ネスト・Variantの継承はすべて展開され、独立した通常Prefabになります。

Material、Mesh、Texture等の参照先アセットの内容は編集しません。非シリアライズフィールドやシーン固有の情報はPrefabに保存できません。反映元の外部にあるシーンオブジェクト参照、Missing Script、未対応のプロパティ形式は黙って省略せず処理を止めます。

Unityの上書き保存は名前等に基づいて既存のfileIDを照合します。同名オブジェクト、同種コンポーネントの重複、構造変更ではfileIDの維持を保証できません。他のアセット・シーンから子要素を直接参照している場合は、更新後に参照を確認してください。Prefabアセット自体のGUIDは維持します。

## バックアップと復元

バックアップはプロジェクト直下の `PrefabFullSyncBackups/<日時と識別子>/` に作成します。Assets外なのでUnityにはインポートされません。元のPrefabとmetaをそのままコピーし、元パスとプレビューを `Restore.txt` に記録します。バックアップに失敗した場合は更新しません。

通常のUndoには対応しません。手動復元は対象のPrefab Modeを閉じ、バックアップの `.prefab` と `.prefab.meta` を `Restore.txt` に記載された元の場所へ上書きしてください。Unityで再インポートされると復元されます。更新後の変更も取り消すため、復元前に必要な変更を別途保管してください。

保存失敗・保存後の値の不一致はバックアップから自動復元を試みます。プレビュー後に変更がある場合は更新せず、再確認を求めます。複製や保存でExecuteAlways、OnValidate、インポート処理等が動く場合があります。これらの任意のスクリプトによる外部への副作用まではロールバックできません。
