# BOOTH Description Studio

[ガイド一覧](../README_JP.md) · [日本語](JP.md) / [English](EN.md) / [한국어](KR.md)

開発ターゲット: **Unity 2022.3.22f1**

開発版ガイドです。Unity・VRChat SDKでの実機確認は未実施です。

## できること

BOOTHの商品説明を組み立て、商品・プリセット・登録一覧を管理します。

## 準備

旧データがある場合はJSONバックアップを用意します。UI言語と商品本文の言語は別で、本文は自動翻訳しません。

## 操作手順

1. `NekkoYa → BOOTH Description Studio` を開きます。
2. プリセットを選んで「新規作成」するか、商品名・カテゴリー・番号を入力します。
3. 対応アバター・事前ダウンロード・内容物・Prefab情報・更新履歴を編集します。必要な項目をONにし、矢印で順番を変えます。
4. 右側の完成プレビューと警告を確認します。警告が解消したら「全文コピー」でBOOTHへ貼り付けます。
5. 「商品として登録」で保存済み商品に追加します。「開く」で既存商品へ戻れます。
6. 「バックアップ出力」で登録情報・商品・プリセットをJSON保存します。「読み込み」は現在のデータを置き換えるため内容を確認します。

## 設定

「登録一覧」で名前・URLを管理します。「登録一覧を編集中の商品に反映」で現在の商品へ更新できます。保存済み本文を無条件に書き換える機能ではありません。独自プリセットは名前を付けて保存します。

## 結果と戻し方

商品データはPCのLocalApplicationData配下 `BoothDescriptionStudio/library.json` へ自動保存します。「今すぐ保存」で状態を確認できます。

## 困ったとき

商品IDの重複、日付形式、貼り付けた数値情報の警告を確認してください。保存できない場合は保存先と権限を確認し、下書きをバックアップ出力してください。保存データを開けない場合、元ファイル保護のため自動保存が止まります。
