## VCC로 설치 (배포 공개 후)

1. VCC의 **Settings → Packages → Add Repository**에 아래 URL을 추가합니다.
2. 프로젝트의 **Manage Project**에서 **NekkoYa Tools for Unity**를 추가합니다.
3. Unity 2022.3.22f1에서 열고 컴파일 완료를 기다립니다. 개발 후보 버전이 보이지 않으면 VCC의 프리릴리스 표시 설정을 활성화하세요.

```text
https://creator-4oru-nero.github.io/NekkoYa-Tools-for-Unity/index.json
```

배포 페이지: https://creator-4oru-nero.github.io/NekkoYa-Tools-for-Unity/

GitHub Pages와 첫 패키지 Release가 공개된 후 사용할 수 있습니다. 설정 파일 추가만으로 공개되지 않습니다. 프로젝트를 백업하고 기존 스크립트 또는 UPM Git 설치와 중복되지 않도록 이전하세요. PhysBone Organizer에는 VRChat SDK Avatars가 별도로 필요합니다.

배포 담당자 안내: [VCC_PUBLISHING.md](VCC_PUBLISHING.md).
