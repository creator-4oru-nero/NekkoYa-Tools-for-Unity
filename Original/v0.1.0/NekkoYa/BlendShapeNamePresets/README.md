# シェイプキーを名前で保存・復元

Unity 2022.3用のEditorツールです。追加パッケージやMCPは不要です。

## 使い方

1. Unityのコンパイル完了後、`Tools > NekkoYa > シェイプキー保存・復元` を開きます。
2. Hierarchyのアバタールートを「対象ルート」に指定します。選択中のオブジェクトは初回表示時に自動設定されます。
3. **FBX更新前**の正しい状態で「現在の値をJSONに保存…」を押します。
4. FBXを更新し、Unityの再インポート完了を待ちます。
5. 必要なら「保存したJSONを開く…」で更新前のプリセットを読み込み、「差分を更新」で確認します。
6. 「名前で復元（Undo対応）」を押します。結果を確認してシーン／Prefabを保存してください。

更新後に「現在の値をJSONに保存」を押して古いプリセットを上書きしないでください。日時付きの別ファイルで履歴を残す使い方を推奨します。

## 動作

- 非アクティブな子を含め、各SkinnedMeshRendererの全キーと値を保存します。0、負の値、100を超える値もそのまま保存します。
- Rendererはルートからの名前の階層で照合します。ルート自体の名前は照合に使わないため、同じ構造のアバター複製にも適用できます。
- Meshのキー名は大文字・小文字を区別し、完全一致で照合します。復元時に最新のindexを解決します。
- 追加されたキーは初期設定で0になります。「新しく追加されたキーを0にする」を外すと現在値を維持します。削除されたキーは表示してスキップします。
- 保存対象にないRendererは変更しません。保存したRendererが見つからない場合や同名兄弟で特定できない場合は、復元全体を停止します。同一オブジェクト上の複数SkinnedMeshRendererも対象外です。
- JSONは明示的に保存したときだけ更新します。自動保存や自動復元はありません。
- 復元は1回のUndoにまとまり、Prefabインスタンスのオーバーライドも記録します。アセット／シーンの保存は手動です。
- Project内のPrefabアセットへの直接適用はしません。シーンインスタンスかPrefab Mode内のオブジェクトを指定してください。Play ModeとAnimationプレビュー中は操作できません。

## 対象範囲と制限

保持するのはRendererに設定された静的なシェイプキー値です。AnimationClip、Animator、Avatar Descriptor、その他コンポーネントの設定は修正しません。アニメーション等が値を書き換える場合は、そちらの調整が必要です。

キー名・子オブジェクト名や階層を変えた場合の自動対応付けはありません。FBX更新前のプリセットがない状態から、すでにずれた値を推測して修復することもできません。

## Unityでの確認項目

この環境ではUnity Editorへの接続がないため、実機のコンパイル／動作確認は未実施です。複製したアバターで次を確認してください。

1. 0と非0の値を混ぜて保存し、値を変更して復元すると全て保存時の値に戻る。
2. FBXのキーの追加・削除・並べ替え後、同じ名前に値が戻り、追加キーは0、削除キーは差分に表示される。
3. 復元後にCtrl+Zで復元直前の値へ戻り、Redoで再適用できる。
4. Prefabインスタンスで復元してシーンを保存し、開き直しても値が残る。
5. 子Rendererの名前変更・削除などで対応が失われると、他のRendererも含め変更されずエラーになる。
6. ウィンドウを閉じたりUnityを再起動したりしても、JSONを開くと復元できる。
